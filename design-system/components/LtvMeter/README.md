# LtvMeter

Loan-to-value on a track with ink ticks at the watch and margin-call thresholds; the fill takes the state colour and the badge says the state.

- Consumer provides: `ltv` (percent), and the loan's own `watch` and `call` thresholds (defaults 60 and 75).
- Show it wherever a borrower decides whether to repay or add collateral. Pair with the distance to the next threshold in copy: "3.2 points from a margin call".
- Minimum width 240px.
