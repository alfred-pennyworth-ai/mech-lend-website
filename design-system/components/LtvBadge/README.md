# LtvBadge

The loan-to-value state as a word plus colour: Healthy (`ltv-safe`, round dot), Watch (`ltv-watch`, diamond), Margin call (`ltv-call`, square), Closed (neutral).

- Consumer provides: `state`; optionally `children` to replace the word (one or two words, e.g. "Paid off").
- The marker shape differs per state so it reads without colour.
- Use beside a loan or asset name and in table rows. Never as a button.
