# Logo

The Visor mark, alone or locked up with the MECH LEND wordmark, drawn in the current theme's `ink` with the status light in `signal`.

- Consumer provides: `variant` (`lockup` default, or `mark`) and `size` (mark height in px; default 24, never below 16).
- Use `lockup` in the app header, marketing nav, statements and email headers; `mark` where space is square (avatars, loading screens, favicons, tight mobile headers).
- Clear space on every side: the height of the slot × 2 (a third of the mark's height). Place it only on `surface`, `graphite`, white, black or calm photography.
- Never recolour the light to anything but `signal`, rotate the mark, outline it, add eyes, antennas or a mouth, or set the wordmark in any face but Michroma.
