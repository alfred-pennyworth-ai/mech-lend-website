# Stat

A label over a figure: the way every number in Mech Lend is shown.

- Consumer provides: `label` (set uppercase by the style), a pre-formatted `value` ("$184,200.00", "62.4%"), optional `note`, `size` (`lg` uses `figure-lg`, `sm` uses `figure`) and `tone` (a colour token name, e.g. `ltv-call`, only when the number itself is a state).
- Format money with two decimals in product UI. Don't abbreviate ("$184K") outside marketing.
