Mech Lend's mark is the **Visor**: a near-square head with one horizontal slot and one status light. It reads as a humanoid visor and as a deposit slot — robot and capital in one shape.

- `mechlend-mark-night.svg` — mark in `#f2f2f0` (Night `ink`) with the light in `#7fc4ff` (Night `signal`). Use on `surface`, `graphite` and photography darker than mid-grey.
- `mechlend-mark-studio.svg` — mark in `#111111` (Studio `ink`) with the light in `#0b63b6` (Studio `signal`). Use on Studio `surface`, white and light photography.
- `mechlend-app-icon-night.svg` — the default app icon and favicon: Night mark on a `#0a0a0a` rounded square.
- `mechlend-app-icon-studio.svg` — light app icon for platforms that need one.

The slot is cut out (transparent), so the ground shows through it. In product UI, prefer the `Logo` component, which draws the same mark in the current theme's `ink` and `signal`.
